### Step 3: Create Data Migration Script

**Create:** `backend/apps/learning/migrations/0XXX_populate_translations.py`

```python
# Generated by Django - DO NOT EDIT MANUALLY except for the data migration logic

from django.db import migrations

def populate_translations_from_indonesian(apps, schema_editor):
    """
    Copy existing Indonesian translations to the new translations JSONField.
    This preserves all existing data while enabling multi-language support.
    """
    # Get models
    Subject = apps.get_model('learning', 'Subject')
    TextBlock = apps.get_model('learning', 'TextBlock')
    VocabularyEntry = apps.get_model('learning', 'VocabularyEntry')
    QuizOption = apps.get_model('learning', 'QuizOption')

    # Migrate Subject
    for subject in Subject.objects.all():
        if subject.indonesian_name and not subject.translations:
            subject.translations = {'id': subject.indonesian_name}
            subject.save()

    # Migrate TextBlock
    for text_block in TextBlock.objects.all():
        if text_block.indonesian_translation and not text_block.translations:
            text_block.translations = {'id': text_block.indonesian_translation}
            text_block.save()

    # Migrate VocabularyEntry
    for vocab in VocabularyEntry.objects.all():
        if vocab.indonesian_translation and not vocab.translations:
            vocab.translations = {'id': vocab.indonesian_translation}
            vocab.save()

    # Migrate QuizOption
    for option in QuizOption.objects.all():
        if option.explanation_indonesian and not option.translations:
            option.translations = {'id': option.explanation_indonesian}
            option.save()

    print("✅ Successfully migrated all Indonesian translations to multi-language format")

def reverse_migration(apps, schema_editor):
    """
    Reverse migration - does nothing since we keep old fields
    """
    pass

class Migration(migrations.Migration):
    dependencies = [
        ('learning', '0XXX_add_multilanguage_support'),  # Replace XXX with actual number
    ]

    operations = [
        migrations.RunPython(
            populate_translations_from_indonesian,
            reverse_migration
        ),
    ]
```

**Note:** Replace `0XXX` with the actual migration number from Step 2.

### Step 6: Create Template Helper Tags

**File:** `backend/apps/learning/templatetags/translation_helpers.py`

Create this new file with translation helper functions:

```python
"""
Template tags and filters for multilanguage translation support
"""
from django import template

register = template.Library()


@register.filter
def get_translation(obj, language_code):
    """
    Get translation for an object based on language code.
    Falls back to Indonesian if translation not found.
    """
    if not obj:
        return ''

    # Try to get from translations JSONField first
    if hasattr(obj, 'translations') and obj.translations:
        translation = obj.translations.get(language_code)
        if translation:
            return translation

    # Fallback to Indonesian field
    if hasattr(obj, 'indonesian_translation'):
        return obj.indonesian_translation
    elif hasattr(obj, 'indonesian_name'):
        return obj.indonesian_name
    elif hasattr(obj, 'explanation_indonesian'):
        return obj.explanation_indonesian

    return ''


@register.filter
def get_subject_name(subject, language_code):
    """
    Get subject name in specified language.
    Falls back to Indonesian name if translation not found.
    """
    if not subject:
        return ''

    # Try translations first
    if hasattr(subject, 'translations') and subject.translations:
        translation = subject.translations.get(language_code)
        if translation:
            return translation

    # Fallback to Indonesian
    if hasattr(subject, 'indonesian_name') and subject.indonesian_name:
        return subject.indonesian_name

    # Final fallback to name
    return subject.name if hasattr(subject, 'name') else ''


@register.simple_tag
def translate_text(translations_dict, language_code, fallback=''):
    """
    Get translation from a translations dictionary.
    Falls back to Indonesian if translation not found.
    """
    if not translations_dict:
        return fallback

    translation = translations_dict.get(language_code)
    if translation:
        return translation

    # Try Indonesian as fallback
    indonesian = translations_dict.get('id')
    if indonesian:
        return indonesian

    return fallback
```

def subject_learning_view(request):
    """科目学習メインページ - Load subjects from database"""
    from apps.learning.models import Subject

    # Get all active subjects from database with prefetch
    subjects = Subject.objects.filter(is_active=True).prefetch_related(

    if not user_language:
        user_language = request.user.native_language if request.user.is_authenticated else 'id'

    return render(request, 'subjects/subject_learning.html', {

```json
{
  "id": "Indonesian translation",

- `en` - English
- `vi` - Vietnamese (Tiếng Việt)
- `zh` - Chinese (中文)

{% endif %}
```

**10. Frontend - Preserve language parameter in navigation:**
```javascript
function navigateToNextPage(url) {
    const urlParams = new URLSearchParams(window.location.search);
    const lang = urlParams.get('lang');

    let fullUrl = url;
    if (lang) {
        fullUrl += (url.includes('?') ? '&' : '?') + `lang=${lang}`;
    }
    window.location.href = fullUrl;
}
```

### Important Notes for Other Sections

1. **Always keep Indonesian as the base language:**
   - Indonesian should be checked FIRST in conditional logic
   - Indonesian should be the fallback in all template helpers
   - Default to 'id' when no language is specified

2. **Preserve existing data:**
   - Never remove the original Indonesian fields
   - Use data migration to COPY (not move) data
   - This allows easy rollback if needed

3. **URL parameter strategy:**
   - Use `?lang=` parameter in URLs
   - Check URL param first, then user preference, then default to 'id'
   - Preserve the parameter when navigating between pages

4. **Template helper usage:**
   - Use `translate_text` for JSONField translations
   - Use `get_translation` for model-level translations
   - Always provide fallback to Indonesian field

5. **Testing each section:**
   - Test with no language parameter (should show Indonesian)
   - Test with `?lang=id` (should show Indonesian)
   - Test with `?lang=en` (should show English if available, else Indonesian)
   - Test navigation between pages (language should persist)
